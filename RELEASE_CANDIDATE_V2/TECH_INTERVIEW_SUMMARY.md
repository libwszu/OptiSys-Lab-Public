# 面试项目说明

我构建了一套 Python 光电系统仿真与报告平台，包含 650 nm 几何成像/CMOS 定位主案例，以及 976 nm 多模光纤到球面透镜的几何追迹第二案例。平台把配置、随机种子、CLI run、数值证据、HTML 报告和 Streamlit 页面串成可复现流程。

Stage 6 聚焦装配误差：我实现了前顶点 pivot 的刚体位姿、共动清口径、镜片局部球面与独立世界坐标球面两条追迹参考，并用装配个体配对采样比较 L2 125/135 mm。名义假设公差下平均捕获差 +18.05 pp；2×压力情景的 paired P05 反转，因此最终结论为 `TRADEOFF_OR_NO_SUPPORTED_GAIN`，而不是把名义优势泛化成全范围鲁棒收益。

我负责仓库内的模型、数据流水线、CLI、报告、UI、测试和审计脚本；NumPy/SciPy、Optiland、Streamlit 等第三方库作为依赖使用。真实源功率、厂家镜片、公差规范和晶体参数没有提供，所以项目结论只限于声明的假设输入。
