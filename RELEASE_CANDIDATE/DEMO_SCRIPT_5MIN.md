# Five-minute demonstration script

## 0:00–0:40 · Position the project

Open the overview. Describe the platform as a reproducible simulation tool with a 650 nm triangulation case and a separate 976 nm pump-path case. Point out that the engineering execution line and scientific verdict line stay separate, and that the evidence ceiling is `SIMULATED / CROSS_CHECKED`.

## 0:40–1:35 · Main triangulation case

Show the G3 demonstration run in the evidence center. It has one assembly and 63 attempts, so it demonstrates that the run pipeline works; it is explicitly not comparable to the 2,000-assembly G2 run. Open the main-case trade-off figure and explain why RMSE, P95 and failure rate are shown together.

## 1:35–2:20 · Change a parameter safely

On the optical bench, change working distance from 200 to 205 mm. Explain that the UI separates preview from a verified run and does not silently overwrite a frozen run. If time allows, run one frame; show the status and source metadata.

## 2:20–3:05 · Read the 976 nm case

Open page F. Point out the 976 nm wavelength, 105 µm core, NA 0.22, normalized source-weight denominator and unknown absolute power. Show that the existing G4 designs differ in clear aperture and therefore are not a same-package optimization comparison.

## 3:05–4:15 · Explain Stage 5

Open the Stage 5 angle and focus figures. Explain that an independent spherical-surface/Snell tracer matched the Optiland output at all four physical surfaces for 4,096 rays per G4 design. In the assumed P1 model, high-angle misses were not aperture clips: the pupil-dependent focus moved forward relative to the original fixed target plane.

## 4:15–5:00 · Show the candidate and limits

Show the equal-aperture position candidate: L2 moves from 125 to 135 mm, changing spacing from 100 to 110 mm. The simulated fixed-target capture rose from 66.09% to 87.06% on an independent 4,096-ray holdout, with a paired ray-bootstrap interval. State that this is not assembly-level tolerance evidence. Finish at the audit ZIP and known-issues list.
