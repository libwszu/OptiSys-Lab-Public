2. 光路模型与假设边界

坐标约定：物点 O=(0,0,0)，+Z 为光轴，+X 横向；激光位于 (B,0,0)，方向 (−sinθ, 0, cosθ)。内部单位 mm / rad / pixel / s，角度仅在配置层用 deg。

模型层级
层级含义本项目的状态
L0虚拟像平面针孔模型，不翻转像已实现，解析可验证
L1-approximate真实倒像单透镜（等凸 N-BK7），几何足迹 ⊛ 标量 Airy 极限本 run 使用（model_level = UNKNOWN）
实测标定对真实相机与镜头做标定**未做**，全项目无实测数据

简化 Airy / 几何核限制：点扩散函数由几何足迹与标量 Airy 圆盘卷积近似，不使用真实波前或衍射传播。PSF 窗半宽上限 max_half_px = 40，窗由 ceil(max|du|,|dv|) + 6·airy_radius + 1 决定。该近似直接导致 kernel_support 的结构上限约 0.972–0.991，也就是 HC3 冲突的物理根源。

Optiland 贡献：optiland 0.6.3 提供真实光线追迹（折射面求交与折射定律），是本项目中唯一非自研的核心光学计算；误差统计、标定、优化、核生成均为自研。

其余发现

勘误与打包缺陷
ID状态令牌内容
PRE-G3-05G2_STRATEGY_AB_NOT_DIRECTLY_COMPARABLEStrategy A is 2000 assemblies x 3 estimators, Strategy B is 200 x 1 estimator over a subset of the same final draw. Only the per-estimator comparison is admissible, and even that is unpaired. The paired A/B bootstrap on the 200 shared assemblies is NOT_RUN and the reason is budget, not impossibility.
PRE-G3-05bCALIBRATION_FRAME_COUNT_CORRECTED_5_TO_9the report claimed 5 calibration frames per unit; g2.py:1046 takes 9 in the non-quick path. The report text was wrong, the code was right, and the cost of strategy B was understated by 80%.
PRE-G3-06.1G2_AUDIT_FORMULA_ERRATUM_REQUIREDthe L1 image-height formula printed in 03_SCIENTIFIC_AUDIT.md section 4 carries an extra 1/Z. At Z=200 mm it yields 648.43 px against a traced 879.95 px, an error of -231.51 px that is 96.5% of the very offset the formula is meant to explain. The error class is an algebraic power of Z, not a sign.
PRE-G3-06.2CLI_REPORT_SCHEMA_3_0_BRANCH_ADDEDcmd_report previously dispatched schema 2.0 and fell through to schema 1.0 for everything else, so a G2 run failed with ConfigError. A three-way resolver _resolve_report_config now dispatches 1.0/2.0/3.0 from the config snapshot, and cmd_report calls render_g2_report for kind == G2.
PRE-G3-06.4G2_AUDIT_PACKAGE_INCOMPLETEthe G2 audit ZIP does not contain pyproject.toml, the CI workflow, or the README, so a recipient cannot reconstruct the environment from the package alone.
G2-07ROBUST_TRADEOFF_OPENrobust buys a 1.19 mm lower RMSE for a 3.14 pp higher failure rate. Any ranking that collapses this to a single score is rejected; the UI shows all three metrics side by side and does not auto-select a winner.
