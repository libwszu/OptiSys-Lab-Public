# 工程发布范围

该工程树采用独立的干净 Git 根历史；不迁移私有研究仓库的 Git 提交、Actions 记录、私有映射或原审计 ZIP。公开入口使用 [OptiSys-Lab-Public](https://github.com/libwszu/OptiSys-Lab-Public)；实际可见性、CI 与 Release 状态以 GitHub 的真实记录为准。

保留两个案例、CLI、六页界面、可分发样本、测试和独立统计复算。未包含全部 G0/G1 原始运行、完整 G3 历史私有树或完整逐面光线轨迹；相应测试范围与已知跳过原因不能混作科学 PASS。

来源、审计包校验与再现步骤见 [公开副本范围](PUBLIC_RELEASE_SCOPE.md)。历史报告中的 full_pytest / remote_ci 是其封包时点的记录，不代表新仓库的实时 CI。科学结论、MIT 与第三方归属不变。
