# 08_NEXT_GATE_PLAN — G2（镜头、公差与优化）

本文件只提出路线，**本轮不执行任何 G2 工作**。

## 1. 入口条件

- G1 审计包判定 PASS/CONDITIONAL；若为 FAIL，先修复 G1，不进入 G2。
- G1 的 V1–V3 证据、数据划分与标定冻结信息仍可追溯。

## 2. G2 范围

| 工作包 | 内容 | 关键约束 |
|---|---|---|
| L1 镜头适配 | Optiland 0.6.3 真正运行镜头案例；单位/坐标/孔径/视场核对；失败光线与渐晕 | 没有真实镜片数据时不得称“高保真”；明确 `L1-approximate` |
| PSF → 图像 | 把镜头 PSF/像差传入成像链；与 L0 高斯对比 | 保持电子数与像元积分守恒；PSF 归一化可核验 |
| 公差采样 | OAT、LHS/MC，`ΔB/Δθ/Δf/Δcx/Δz` 假设；约 200 样本预检 | 种子独立、缓存键、断点续算 |
| 名义/鲁棒优化 | 同一预算、同一测试集；`J_nom` 与冻结权重 `J_robust` | 不可事后调权重；不可行设计标 infeasible |
| 独立 MC 复评 | 新种子约 2,000 样本；装配后不重标定 vs 每台独立标定 | 两种策略分开报告；给出置信区间 |
| 报告 | 复用 G1 评价/报告模块 | 不复制粘贴成第二套平台 |

## 3. 预估资源

- Optiland 单次镜头追迹 + PSF：需先做 30–100 帧基准，再决定是否 2/4 进程。
- 公差 MC：2,000 设计 × 每设计 1 帧 → 生成/拟合成本沿用 G1 实测（约 0.16 s/帧单进程）；若全量约 5 分钟，可接受；更大规模需先分块优化。
- GPU 仍默认不用；只有在 torch/CUDA 可用且有同输入一致性证据时才评估。

## 4. 验收（建议）

- V4：镜头模型与独立追迹/解析薄透镜对照，单位/条件数/失败光线清单齐全。
- V5：同一独立测试集上 baseline / nominal / robust 的 RMSE、P95、失败率与 CI；预算一致。
- 缓存/并行不改变科学结果（同输入复算一致）。
- `EXECUTION_PASS` 与 `SCIENTIFIC_CLAIM_SUPPORTED` 分开；优化无改善也如实通过执行完整性。

## 5. 明确不做

- 真实相机/镜头采购与实测（V7 仍 `NOT_RUN`）。
- GUI（G3）。
- 976 nm 案例（G4）。
- 把 L1 近似 PSF 描述成实测 PSF。

## 6. 需要用户确认的事项

- 是否有可用的真实镜头料号/Zemax 文件/实测 PSF；没有则以“近似 L1 + 敏感性分析”交付。
- 公差预算规模是否允许 2,000+ 样本的独立 MC（预计数分钟到数十分钟）。
