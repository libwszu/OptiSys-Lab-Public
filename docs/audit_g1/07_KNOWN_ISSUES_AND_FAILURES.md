## 3. 负结果

| 项 | 结果 | 解释 |
|---|---|---|
| 2D 弱信号 | 失败率 13.93%（241/280 有效），RMSE 0.0874 mm | 弱信号（8k e，背景 200 e/px）下拟合更容易触发 `MODEL_MISMATCH`/`FIT_NOT_CONVERGED`；未删帧 |
| 1D 估计器 | 全样本 RMSE 0.0689 mm，差于质心 0.0497 与 2D 0.0444 | u 方向 1D 模型可辨识，但仅用列投影、v 用行质心；不是“更好”的算法 |
| 并行单帧耗时 | 质心 0.45 vs 0.24 ms；1D 29.3 vs 16.4 ms；2D 8.7 vs 4.7 ms | 内存带宽竞争；端到端仍 2.35× |
| GPU | NOT_TESTED | 无 torch、无同输入一致性证据；不声称加速 |

## 5. 证据自指与索引

- `report.html` 的文件索引是生成时刻快照，不含自身；完整清单以 `manifest.json` 为准。
- `manifest.json` 不列自身哈希；`SHA256SUMS.txt` 不列自身。
- G0 ZIP 未嵌套，仅记录 run id 与 SHA-256；复核需用户在原始目录核对。
