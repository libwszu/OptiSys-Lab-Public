## 2. 坐标系与符号约定

- 右手系；相机光心 `O = (0,0,0)`；光轴 `+Z`；横向 `+X`；`v` 轴向下仅作为图像坐标，不与物理 `Y` 混用。
- 激光出射点 `(B,0,0)`，方向 `(-sinθ, 0, cosθ)`；`B > 0`。
- 目标平面 `Z = Z0 > 0`；交点 `X_L = B − Z tanθ`。
- 虚拟像平面位于光心前方，**不翻转**；`u = cx + fx (B/Z − tanθ)`。
- 像素中心取整数坐标，`u ∈ [0, W−1]`、`v ∈ [0, H−1]`；`cx, cy` 使用同一约定。
- 角度内部一律 rad；长度内部一律 mm；像元尺寸内部 mm。

## 3. 数值阈值（工程选择，已写入配置）

| 参数 | 值 | 含义 | 依据 |
|---|---|---|---|
| `min_baseline_mm` | 1.0 mm | 低于此基线拒绝计算 | 工程可观测性下限，**非** PDF 给定；需 G2 机械约束确认（OI-002） |
| `singular_denominator_px` | 1e-6 px | `|u−cx+fx tanθ|` 低于此值判奇异 | 防止反演放大到无意义量级 |
| `range_epsilon_mm` | 1e-6 mm | 工作范围边界的舍入保护带 | 仅吸收 `300.00000000000006` 类浮点误差，不扩展物理范围 |
| `sensor_margin_px` | 0 | 像元边缘内缩 | 默认不内缩；可配置 |
| U 比对阈值 | 1e-8 px | 解析 vs 独立链 | PDF 第 12 页建议 |
| X 比对阈值 | 1e-9 mm | 解析 vs 独立求交 | 与 U 阈值同量级，按 mm 换算 |
| Z 相对阈值 | 1e-9 | 反演一致性 | 双精度算术下限的保守上界 |
| 导数相对阈值 | 1e-5 | 有限差分对照 | 中心差分 + Brent 容差决定 |

## 4. 模型等级与边界

**L0（当前唯一实现）**：理想针孔 + 共面二维 + 解析投影。仅用于公式验证、算法单测与几何一致性；**不得**用于宣称工业精度、景深、像差、散斑或 SNR 性能。

以下内容在 G0 明确不存在：

- 镜头畸变、主点偏移的真实标定、景深、衍射、像差、PSF。
- 像元积分、曝光、量子效率、光子散粒噪声、暗电流、读出噪声、ADC、饱和/裁切。
- 光斑定位算法、ROI 检测、亚像素估计、标定拟合、训练/测试分离。
- 公差采样、Monte Carlo、鲁棒优化、Pareto 分析。
- 真实表面散射、相干散斑、多次反射、遮挡、非共面旋转。
- GUI、交互式参数修改、视频演示。
- 976 nm 泵浦光路。

## 5. 证据等级

| 等级 | 本 Gate 是否使用 | 说明 |
|---|---|---|
| FORMULA | 是 | 解析式与单位约定 |
| SIMULATED | 是 | 由可复现程序产生的数值（几何扫描） |
| CROSS-CHECKED | 是 | 独立向量/矩阵链、Brent、有限差分 |
| MEASURED | **否** | 无任何仪表/相机数据 |
| VALIDATED | **否** | 无校准集 + 独立测试集 |

一次仿真与生成它的公式一致，只能证明程序实现一致，不能升级为实测验证。

## 6. 已知限制

1. `v` 在该模型中恒等于主点行坐标（目标位于 XZ 平面），真实行列方向需标定。
2. θ 的独立对照只覆盖 −3°/0°/+3°；配置允许 ±80°，但未在本 Gate 的对照网格内验证。
3. 反演的 `OUT_OF_RANGE` 分支保留 `candidate_Z_mm` 供诊断，但 `Z_mm` 置 NaN；调用方不得使用候选值作为测量。
4. `OUT_OF_SENSOR` 的 `u_px` 仍会返回作为几何诊断，`visible=False`；这不是有效测量。
5. `image.*` 与 `run.repeats` 在 G0 未被使用，`metrics.json` 中显式列出。
6. Optiland 0.6.3 可导入，但未运行任何镜头案例；不构成 L1 光学能力声明。
7. GPU 未测试：G0 无张量负载，torch 未安装。
8. GitHub Actions 配置未在远端运行（`CI_NOT_VERIFIED`）。
9. 本项目的 `report.html` 是静态 G0 报告，不是 G3 的交互式应用。
