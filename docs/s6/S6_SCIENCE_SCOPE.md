# S6 科学范围（预注册）

## 唯一科学问题

S5 的假设 P1 光路在理想居中条件下仅将 L2 主平面从 125 mm 移到 135 mm，名义捕获率由约 66.09% 升至 87.06%。S6 检验：在独立核验的球面刚体偏心、倾斜和轴向扰动模型下，固定 1 mm 半径接收区的条件性收益是否仍存在，其代价和失败尾部是什么。

## 几何与来源

- 976 nm 单色几何追迹；光纤芯径 105 µm、NA 0.22；近场均匀面积盘、远场均匀立体角均为假设分布，源功率 `UNKNOWN`。
- L1 为假设 N-BK7 等凸 singlet，f=25 mm、12 mm 通光口径、2 mm 中心厚度、主平面 z=25 mm；L2 同为假设 N-BK7 等凸 singlet，f=100 mm、12 mm 通光口径、2 mm 中心厚度。半径、物理面坐标和折射率来自被冻结的 S5/G4 光学模型，完整数值在 run 的 `config_snapshot.yaml`；135 mm 候选只平移 L2，不能变更其他设计量。
- 两个对比：`baseline125` 与 `s5_position135`。固定世界接收面 z=225 mm、有效半径 1 mm；主要对比中目标不随镜片移动。
- 不建模厂商镜片号、真实安装基准、涂层/Fresnel 损耗、波动/衍射、相干模态干涉、绝对功率、晶体吸收和热效应；无实物制造参数。

## 刚体与表面定义

每片镜的局部原点固定在其前顶点，刚体转动绕该前顶点 pivot 发生。配置的平移 `dx,dy,dz` 作用于 pivot；主动旋转矩阵为 `Rz(roll) @ Ry(tilt_y) @ Rx(tilt_x)`，角度先转换为弧度。局部到世界坐标 `p_w = R p_l + t`、`d_w = R d_l`，逆变换为 `p_l=R.T(p_w-t)`、`d_l=R.Td_w`。前、后球心和表面由 S5 的有符号半径及中心厚度生成；圆形清口径随镜片坐标系共动。

## 证据级别

- `ASSUMED_MODEL`：上述假设光源和镜片模型。
- `MODEL_CROSS_CHECKED`：S6-A 的局部坐标与独立世界坐标实现，在已登记位姿范围、全矩阵及失败负例上的数值核验通过。
- `ASSEMBLY_SAMPLED`：固定假设公差分布下按装配个体抽样的几何结果；不是实际制造公差。
- `EXPERIMENTALLY_MEASURED`：本轮无授权实测，必须标为 `NOT_AVAILABLE`。

几何图和仿真统计仅说明本模型。即便 S6-C 支持 135 mm，也只能写作 `SUPPORTED_WITHIN_ASSUMED_P1_AND_TOLERANCES`。
