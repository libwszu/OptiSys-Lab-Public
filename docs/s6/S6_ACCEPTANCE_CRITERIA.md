# S6 验收条件（结果前冻结）

## A：非共轴独立参考

两条实现必须分别完成交点求解与 Snell 折射：A 在镜片局部系解球面并变换到世界系；B 在世界系解变换后的球面，并自行求法向与折射。不得共享求交/折射结果。普通非病态表面命中容差为世界坐标最大分量差 `1e-7 mm`、出射方向最大分量差 `1e-8`；固定世界目标面坐标差 `1e-6 mm`。超过近切线判据 `disc/R² <= 1e-10`、入射余弦绝对值 `<=1e-6` 或 Snell `k<=1e-10` 的表面单独打 `ILL_CONDITIONED`，不混入普通 max 误差。

通过矩阵包括：零位与 S5 4,096 条射线/表面/目标记录逐条对照；L2 纯轴向 +10 mm 且 target 仍为 225 mm；L1/L2 分别 ±x/±y 偏心至 0.15 mm、±x/±y 倾斜至 0.30°、轴向至 ±0.90 mm；不少于四个复合位姿；roll 圆对称零效应；轴上/离轴、内外 pupil 与低/高角射线；边缘光阑截断、近切线、目标外、反向/无效源、无效材料/位姿/目标等负例。旋转需满足正交误差 `<=1e-12`、determinant 与 +1 的误差 `<=1e-12`；每条成功射线方向范数误差 `<=1e-12`；终端权重账本绝对残差 `<=1e-12`。

`PASS` 要求全矩阵与两个独立路径通过，参考记录完整且账本闭合；`QUALIFIED` 只限缺失范围明确且无矛盾的局部通过；任一重要几何分支矛盾、绕轴 pivot 不明、光阑不共动、物理状态不闭合或负例漏检为 `FAIL/STOP_PHYSICS`，S6-C 不运行。

## B：两项边界分别诊断

- 焦面扫描相对于 z=225 mm 的偏移固定为 `[-60,-45,-35,-25,-15,-5,0,+10] mm`，镜片不动。所有点先验证位于 L2 最后实体面下游。报告以所有输入源权重为分母的捕获率、所有到面光线相对世界光轴中心的 `r80/r90/RMS`，另列接收区内条件 r90。
- 镜位扫描固定 target z=225 mm、其它处方不变，L2 主平面位置为 `[125,130,135,140,145] mm`。检查镜片表面序列、正间隙和失败账本。
- 只有内部严格极值、边缘点非并列，且预注册独立种子复核支持时才称 `BRACKETED`。100% 捕获平台或边界点最高均不算括定；粗网格内点峰只标 `EXPLORATORY_ONLY`。

## C：装配级主比较

主估计量为同一 assembly ID 上 `capture_135 - capture_125`，捕获分母是所有输入 ray source weight。对每个设计、每个 assembly 保存终端分类权重；无效装配的 attempted-design capture 记零并计入分母，同时报告原因。有效装配条件结果只能作为附表。候选与基线复用同一源射线和同一相对误差向量。

计划每个误差情景 200 个独立装配、每装配/设计 1,024 rays：零公差、名义公差、名义标准差 0.5 倍的收紧情景、名义标准差 2 倍的加严压力情景。名义分布是每镜 x/y 偏心 sigma 0.05 mm、x/y tilt sigma 0.10°、z sigma 0.30 mm 的独立零均值、±3 sigma 截断正态假设；相关性假设为独立。它不是供应商指标。holdout 前固定 assembly/source/bootstrap 种子；S5 seed 976053 不得用于 S6-C。

主置信区间为至少 2,000 次 paired cluster bootstrap，重采样单位是 assembly，不是 assembly 内的 rays。报告均值差、95% CI、每设计的 P05/P50/P95、配对差分分位、失败/无效/截光/目标外/追迹失败、全平面半径统计和有效组数。若 CI 含零，不支持平均改善；若平均 CI 排除零但低尾/失败指标显示代价，则判 `TRADEOFF_OR_NO_SUPPORTED_GAIN` 并列出权衡。只有参考 PASS、holdout 完整、无重复/漏项、均值差 CI95 下界大于零且没有未披露的失败代价，才可给有限范围 `SUPPORTED_WITHIN_ASSUMED_P1_AND_TOLERANCES`。所有结论均非实测结论。
