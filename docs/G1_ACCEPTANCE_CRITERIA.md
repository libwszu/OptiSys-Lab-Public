# G1_ACCEPTANCE_CRITERIA（运行前冻结）

冻结时间：2026-10-19（在 G1 正式实验开始之前）
版本：`g1-accept-1.1`

变更记录：1.1（正式运行前）把 V2 的单次 10,000 抽样改为 **3 次独立重复、合并 n=30,000**；原因是单次 10k 在 99% 区间下会因一次约 2.7σ 的正常涨落误拒（已在开发期观察到），而 3 次重复全部保留、门槛为合并样本通过且至少 2/3 重复通过。该修改发生在任何正式结果产生之前。
修改规则：任何阈值只能在正式实验开始**之前**以新版本修改并保留旧版本；运行后不得为提高通过率而放宽。

## 3. 质量门

### V1-A：能量与面积积分

| 检查 | 口径 | 阈值 |
|---|---|---|
| 离散总权重 vs 连续总量 | 光斑中心距芯片边缘 ≥ 8σ、非裁切 | 相对偏差 ≤ **1%** |
| 像元积分正确性 | erf 解析权重 vs 二维 Gauss–Legendre 数值积分（抽样 64 像元） | 每像元相对差 ≤ **1e-6**，总量 ≤ **1e-9** |
| 裁切行为 | 边缘光斑 | 记录 `capture_fraction`，**不得**把残余权重重归一化；捕获率随偏移单调下降 |

### V1-B：亚像素与边界

| 检查 | 阈值 |
|---|---|
| 无噪声、完整光斑，平移 0.25 / 0.37 / 0.50 px，2D 拟合中心误差 | ≤ **0.01 px** |
| 同上，1D 拟合 u 误差 | ≤ **0.02 px** |
| 同上，质心 u 误差 | ≤ **0.05 px** |
| 光斑中心移出芯片 | 必须返回 `OUT_OF_SENSOR` 或 `PARTIAL_SPOT`，不得 OK |

### V2-A：单像元噪声统计（10,000 抽样/工况，99% 区间）

| 工况 | 理论 | 判据 |
|---|---|---|
| 暗场（仅背景+暗电流） | E=µbg+µdark，Var=µbg+µdark+σr² | 合并 n=30,000 的均值与方差均在 99% CI 内，且 ≥2/3 重复通过 |
| 信号 + 泊松 | E=µsig+µbg，Var=µsig+µbg+σr² | 同上 |
| 仅读出（零信号、零背景、零暗） | E≈0，Var=σr² | 均值 CI、方差比 χ²(0.5%,99.5%) |
| 三噪声同时 | 相加模型 | 同上 |
| 零读出 | Var=µ | 同上 |

统计规则：每工况 3 次独立 10,000 抽样（独立 seed），合并后按 n=30,000 计算均值区间 `mean ± 2.576·sqrt(var_true/n)` 与方差区间 `[(n-1)s²/χ²_{0.995}, (n-1)s²/χ²_{0.005}]`；门槛为合并检验通过且至少 2/3 单次重复通过。每工况与每次重复均报告 n、seed、理论值、实测值、CI、状态；失败案例保留。

### V2-B：曝光、饱和、量化

| 检查 | 阈值 |
|---|---|
| 暗电流随曝光线性增长（1–20 ms，5000 e/s/px） | 斜率相对误差 ≤ **5%** |
| 强信号饱和 | 饱和像元标记 `SATURATED`，ADU 不超过位深上限 |
| 量化/黑电平 | `ADU = floor(e/e_per_adu)+black`，边界不越界 |

### V3-A：定位器

| 检查 | 阈值 |
|---|---|
| 三种算法统一接口、同帧比较 | 必须 |
| 无噪声完整光斑 2D 拟合 | ≤ 0.01 px |
| 坏帧（无信号/饱和/空 ROI/双峰） | 必须返回非 OK 或显式质量标志 |
| 读取真值作为输入 | **禁止**；代码审查 + 测试保证 |

### V3-B：标定与数据隔离

| 检查 | 阈值 |
|---|---|
| calib/validation/test ID 交集 | **空集**（自动断言） |
| 标定使用测试数据 | **禁止**（代码路径审查） |
| `a` 恢复（medium 条件，质心/2D） | 相对误差 ≤ **1e-2**；oracle 无噪声 ≤ **1e-4** |
| `b` 恢复 | 绝对误差 ≤ **0.5 px** |
| 四个几何参数唯一辨识 | **不声称**；文档必须写明仅 `a,b` 可辨识 |

### 端到端

| 指标 | 要求 |
|---|---|
| 每帧记录 | sample_id、split、Z/u/v 真值、条件、seed、各状态、质量标志、估计值、误差、饱和比、捕获率、耗时、config/code hash |
| 指标 | Bias、RMSE、P95(|error|)、每距离重复性、失败率、耗时中位/P95 |
| 分母 | 失败率以**全部尝试帧**为分母；精度指标仅对有效帧，同时报告 `N_valid/N_attempted` |
| 分组 | 距离、条件；bootstrap 按距离聚类 |

## 4. Gate 聚合规则

G1 PASS 必须同时满足：

1. V1–V3 的全部机器检查通过；
2. G0 几何回归通过（解析 vs 独立链仍 ≤1e-8 px，导数符号为负）；
3. pytest：`failed = 0`、`skipped = 0`、`passed ≥ gate_requirements.G1.min_tests_passed`；
4. 数据集规模、划分、代表帧、报告与 manifest 一致；
5. CLI 在任一核心门失败时返回非零退出码。

任一不满足 → `FAIL`；证据不完整但无科学矛盾 → `PARTIAL`。`SCIENTIFIC_CLAIM_STATUS` 单独判定：本轮最多支持“L0 仿真链路内部一致、误差可量化”，不支持工业精度或实测验证。

## 5. 明确不采用的阈值

- 不以 `0.1 mm` 作为“达标”阈值；只报告仿真条件下实际误差与不确定度。
- 不因某算法表现差而删除该算法或坏帧；负结果保留。
- 不把 `peak_electrons` 重新解释为总电子数；G1 使用 `signal.total_electrons`。
