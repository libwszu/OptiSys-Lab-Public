## SD-001：式 (3) 的 `dZ/du` 符号与式 (2) 的有符号求导不一致

| 项目 | 内容 |
|---|---|
| 来源 | PDF 第 8 页，4.2 节，式 (2) 与式 (3) |
| 严重度 | P1（符号/单位类，但只影响有符号用法，不影响幅值） |
| 发现日期 | 2026-10-19 |
| 状态 | 已量化、已隔离；等待任务书作者确认措辞（不阻塞 G0） |

### 1. 原文

式 (2)：

```text
u(Z) = cx + fx * (B/Z - tan(theta))
Z(u) = fx * B / (u - cx + fx * tan(theta))
```

式 (3)：

```text
∂Z/∂u = Z^2 / (fx * B)          # 原文为正号
σZ ≈ (∂Z/∂u) * σu
```

### 2. 冲突

对式 (2) 的第一式做有符号求导：

```text
du/dZ = fx * d/dZ (B/Z) = -fx*B / Z^2
dZ/du = 1 / (du/dZ)     = -Z^2 / (fx*B)
```

只要 `B > 0`、`fx > 0`、`Z > 0`，`dZ/du` 必为负。物理解释：目标变远时，光斑向主点移动，`u` 减小；因此同样的 `u` 增量对应更远的 `Z` 增量方向相反。

式 (3) 印刷为正号，与式 (2) 不一致。

### 3. 独立证据（不止一种方法）

| 方法 | 结果 | 位置 |
|---|---|---|
| 符号微分 | `dZ/du = −Z²/(fxB)` | `src/optisys/geometry/coplanar.py` docstring |
| 独立矩阵链的中心差分 `du/dZ` | 在 Z=100…300、θ=−3/0/+3° 全部为负，且与解析值相对差 ≤ 6.1e-10 | `tests/unit/test_derivatives.py::test_du_dZ_matches_finite_difference` |
| 独立 Brent 反演的差分 `dZ/du` | 与解析值相对差 ≤ 1e-6 | `tests/unit/test_derivatives.py::test_dZ_du_matches_inverse_finite_difference` |
| 逆映射单调性 | `u(Z)` 严格递减；`reference.invert` 在 `[50, 600] mm` 上括号唯一 | `tests/unit/test_independent_chain.py` |
| 数值复现 | Z=200 mm：`dZ/du = −0.8625000000000002` mm/px；Z=300 mm：`−1.9406250000000005` mm/px | `repro/verify_g0.py` 输出 |
| 与 PDF 印刷数字比对 | 幅值 `0.862500` vs 印刷 `0.8625`；`1.940625` vs `1.9406`（4 位舍入） | `tests/reference/test_pdf_values.py` |

结论：**PDF 的数值（0.8625、1.9406）是幅值，正确；缺失的是符号。** 这不是整份任务书错误，也不是实现可以静默改写公式的理由。

### 4. 暂定处理

1. 实现同时提供：
   - `du_dZ(Z)`：有符号，负值，单位 px/mm；
   - `dZ_du(Z)` / `inverse(u).dZ_du_mm_per_px`：有符号，负值，单位 mm/px；
   - `abs_sensitivity(Z)`：`|dZ/du|`，仅用于误差预算。
2. 文档与报告在讨论误差预算时一律写 `|dZ/du|`，避免把符号带入 `σZ`。
3. 不修改 PDF 式 (2)，也不把式 (3) 改写成“原文错误”；在追溯表中保留原文并标注差异。
4. 测试显式断言有符号值为负（`test_signed_derivatives_are_negative_for_positive_baseline`），防止未来有人“修好”成正号。

### 5. 何时可以认为正号也成立

只有在**图像坐标方向与物方 +X 相反**（真实相机行列翻转且未在式 (2) 中体现）时，`u` 的定义会变成 `u = cx − fx(B/Z − tanθ)`，此时 `du/dZ > 0`、`dZ/du > 0`。但 PDF 式 (2) 明确写的是 `+ fx(...)`，且第 8 页说明“真实图像左右方向要通过标定确认”。因此：

- 在当前约定的虚拟像平面下，负号是唯一自洽结果；
- 若未来标定发现相机镜像，应通过**显式的图像方向参数**处理，而不是改动物理公式的符号。

### 6. 对主结论的影响

| 结论 | 是否受影响 |
|---|---|
| `u(Z)` 与 `Z(u)` 数值 | 不受影响 |
| `|dZ/du|` 与 PDF 的 0.8625 / 1.9406 | 不受影响（幅值一致） |
| `σu ≲ 0.052 px @ 300 mm → 0.1 mm` 的误差预算 | 不受影响（只用幅值） |
| 反演单调性与越界判断 | 不受影响（已按负号实现） |
| 报告中的导数曲线/表格 | 明确标注“有符号为负，图示为幅值” |

### 7. 是否需要用户确认

代码层面不需要：负号有独立数值证据，且与 PDF 自身数值不矛盾。文档层面建议任务书作者把式 (3) 改写为 `|∂Z/∂u| = Z²/(fxB)`，或在式 (2) 中显式声明图像方向。该建议不改变任何已交付结果。
