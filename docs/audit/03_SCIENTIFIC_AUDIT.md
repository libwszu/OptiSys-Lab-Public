# 03_SCIENTIFIC_AUDIT — G0 科学审计

## 1. 声明范围

本 Gate 只支持一个科学声明：

> 在明确的坐标与单位约定下，理想针孔共面三角测量的解析实现，与一条独立构造的向量/矩阵数值链在双精度舍入量级上一致；病态与越界输入被显式拒绝。

不支持的声明：传感器精度、重复性、SNR、景深、像差、散斑、标定后精度、产品性能、实测验证。

证据等级：`FORMULA` + `SIMULATED` + `CROSS-CHECKED`。没有 `MEASURED`，没有 `VALIDATED`。

## 2. 坐标与符号契约

```text
右手系；O = (0,0,0) 为相机光心
光轴 +Z；物方横向 +X；目标平面 Z = Z0 > 0
激光出射点 (B, 0, 0)，B > 0
激光方向 (-sinθ, 0, cosθ)，即向 +Z 传播并向 -X 偏 θ
虚拟像平面在光心前方，不翻转
像素中心取整数坐标，u ∈ [0, W-1]
```

关键推论：`u(Z)` 随 `Z` 单调递减（光斑向主点移动），因此 `du/dZ < 0`、`dZ/du < 0`。

## 3. 实现的公式

| 量 | 公式 | 代码 |
|---|---|---|
| 交点横坐标 | `X_L(Z) = B − Z tanθ` | `CoplanarGeometry.forward` |
| 有效焦距 | `fx = f_mm / p_mm` | `config.config_from_dict` |
| 像点列坐标 | `u(Z) = cx + fx (B/Z − tanθ)` | 同上 |
| 反演 | `Z(u) = fx B / (u − cx + fx tanθ)` | `CoplanarGeometry.inverse` |
| 像点灵敏度 | `du/dZ = −fxB/Z²` | `du_dZ` |
| 有符号深度灵敏度 | `dZ/du = −Z²/(fxB)` | `dZ_du` |
| 误差预算用幅值 | `|dZ/du| = Z²/(fxB)` | `abs_sensitivity` |

## 5. 独立对照链为何独立

`geometry/reference.py` 刻意不走解析式：

1. **方向**：由 `rotation_y(-θ)` 作用于 `(0,0,1)` 得到，不使用 `tanθ`。
2. **求交**：目标平面用三个非共线、非轴对齐的点表示，解 3×3 线性方程组 `M[t,a,b]ᵀ = p1 − P0`；不是点积闭式。
3. **投影**：用齐次 3×4 相机矩阵 `K[R|t]` 做透视除法；不是标量 `u = cx + fx X/Z`。
4. **反演**：对参考前向模型做 Brent 求根（`xtol=1e-13`），不是闭式反演。
5. **导数**：对参考链做中心差分（`h = 1e-6·Z`），不是对解析式差分。

因此，“两个函数调用同一公式”这种伪独立验证不成立。

## 7. 边界与病态行为

| 输入 | 状态码 | 是否返回数值 |
|---|---|---|
| `Z = NaN/Inf` | `NONFINITE_INPUT` | `u = NaN` |
| `Z ≤ 0` | `INVALID_DEPTH` | `u = NaN` |
| `B < min_baseline_mm` | `BASELINE_DEGENERATE` | `u = NaN` |
| `Z` 在工作范围外 | `OUT_OF_RANGE` | 返回几何诊断值，`visible=False`，不得当作测量 |
| `u` 使分母 < 1e-6 px | `SINGULAR_GEOMETRY` | `Z = NaN`，候选值也为 NaN |
| 反演分母为负 | `INVALID_DEPTH` | `Z = NaN`，`candidate_Z < 0` 仅诊断 |
| 像点出界 | `OUT_OF_SENSOR` | 返回 `u` 诊断，`visible=False` |

所有失败路径都有测试；`test_inverse_never_returns_nan_as_success` 逐一断言“状态非 OK 时 `Z` 必须为 NaN”。

## 8. SD-001：PDF 式 (3) 的符号

对式 (2) 求导得 `dZ/du = −Z²/(fxB)`；PDF 式 (3) 印为正号。独立 Brent 反演与有限差分均确认负号。PDF 的数值 0.8625 / 1.9406 是幅值，本实现精确复现（0.862500 / 1.940625）。

处理：实现保留有符号负值，误差预算与图示使用 `|dZ/du|`；不改写 PDF 公式，不静默“纠正”。详见 `docs/SPEC_DISCREPANCIES.md` 与 `tests/reference/test_pdf_values.py`。

## 10. 确定性与随机性

G0 几何完全确定：相同配置与输入给出逐位相同结果。`run.seed` 仅用于基准采样与未来的随机流，不改变几何结果。没有 Monte Carlo，因此不存在“换种子结论变化”的问题。

## 11. 什么会推翻本结论

- 参考链与解析式在同一输入下出现 > 1e-8 px 的系统偏差；
- 端点或奇异附近出现“看似正常”的有限值；
- 单位换算（µm→mm、deg→rad）出现 1000× 或 π/180 量级错误；
- 反演在合法范围内不单调或不可逆。

以上均有对应测试；若未来修改代码导致任一失败，G0 必须重新判定，不能沿用本 PASS。
