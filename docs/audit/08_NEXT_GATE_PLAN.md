# 08_NEXT_GATE_PLAN — G1（L0 成像、传感器噪声、定位与标定闭环）

本文件是给下一轮开发/审计的最小合理路线。**在 G0 通过后**才可执行；不得把 G1 的模块提前塞进 G0 证据。

## 1. 目标

形成第一个可复现的端到端闭环：

```text
config -> 共面几何 -> 理想高斯光斑 -> 像元积分 -> 期望电子数
       -> 泊松/暗电流/读出噪声 -> 增益/ADC/饱和 -> 定位器 -> 距离反演
       -> 标定/验证/测试分组 -> 误差与失败率指标 -> 报告
```

## 2. 工作包

| # | 模块 | 内容 | 关键约束 |
|---|---|---|---|
| 1 | `imaging/spot.py` | 2D 高斯光斑，按像元做解析积分（误差函数），不点采样 | 非裁切时总电子数守恒 ≤ 1% |
| 2 | `imaging/sensor.py` | `µe = η·P·t/(hc/λ) + 暗电流 + 背景`；泊松、读出高斯、增益、位深、饱和/裁切 | 保留电子数与 ADC 的对应；`peak_electrons` 只是简化曝光参数 |
| 3 | `estimators/` | 阈值加权质心、1D 高斯拟合（投影方向需声明）、2D 稳健拟合（`least_squares` + soft_l1） | 统一返回 `u_hat, v_hat, quality, status, time`；收敛≠有效 |
| 4 | `calibration/` | 系统距离标定：已知 Z 样本拟合几何参数/残差校正 | 相机内参与系统标定严格分离 |
| 5 | `evaluation/` | 校准/验证/测试三分组；Bias、RMSE、P95、重复性、**全样本失败率**、耗时 | 同一随机图像实例不得跨集合 |
| 6 | `cli` | `simulate` 扩展到成像；`evaluate` 输出分组指标 | 未实现命令继续返回 `NOT_IMPLEMENTED` |

## 3. 验收（G1 PASS 条件）

| 层 | 测试 | 通过口径 |
|---|---|---|
| V1 | 非裁切能量守恒 | 离散前后总期望电子数相对偏差 ≤ 1% |
| V1 | 光斑平移 | 高斯中心平移 Δu 后，估计中心偏差 < 0.01 px（无噪声） |
| V1 | 裁切/出界 | 必须标记裁切帧，不参与能量守恒阈值 |
| V2 | 噪声统计 | 10,000 帧零信号 + 固定曝光；样本均值/方差与理论值在 95% CI 内；给出功效/样本量依据 |
| V2 | 暗电流/读出分离 | 改变曝光时间，暗电流斜率与设定值一致（CI 内） |
| V3 | 三种定位器 | 统一接口、固定测试集、误差与耗时表；故意坏帧（饱和、无光斑、越界 ROI、双光斑）全部可识别 |
| V3 | 数据隔离 | 校准/验证/测试样本 ID 交集为空（自动断言） |
| 端到端 | 闭环 | config → 图像 → 定位 → 反演/标定 → 误差指标，一条命令可复现 |

## 4. 分层采样与预算

| 阶段 | 规模 | 目的 |
|---|---|---|
| 冒烟 | 3 个距离 × 3 次重复 | 链路连通、图像可保存 |
| 流程验证 | 41 个距离 × 10 次重复 × 3 种噪声条件 = 1,230 帧 | 检查坏帧率与异常值 |
| G1 正式 | 41 × 100 × 3 = 12,300 帧 | 误差曲线与分组指标 |

预算估算（基于 G0 实测，`0.15 ms` 仅几何；成像预计 5–20 ms/帧）：

- 图像生成：12,300 × 20 ms ≈ 246 s（单进程）
- 定位：质心 ~1 ms；2D 拟合 ~10–50 ms → 12,300 × 50 ms ≈ 615 s
- 合计可能接近 900 s 上限；如超时，先降重复数并明确标注“探索性”，不得把缩减样本标成完整验证。

## 5. 资源策略

- 继续单进程 NumPy；若定位拟合成为瓶颈，再基准 2/4 进程，并以实测 ≥1.3× 为采纳门槛。
- 图像用 `float32` 存储、`float64` 计算关键统计；单帧 1280×1024 float32 ≈ 5 MB。
- 不启用 GPU：无张量负载，且 torch 未安装。
- 长任务分块写 checkpoint（样本 ID、种子、状态），中断只补缺失样本。

## 6. 风险

| 风险 | 早期信号 | 应对 |
|---|---|---|
| 把简化 PSF 说成“高保真” | 报告出现“真实散斑/像差”措辞 | 固定 L0 标签；G2 才接镜头 |
| 噪声参数无来源 | QE/读出/暗电流被写成“实测” | 明确 `ASSUMPTION`，给敏感性范围 |
| 定位器过拟合模拟器 | 换 PSF/噪声后精度骤降 | 多条件独立测试，报告泛化限制 |
| 标定泄漏 | 测试集 ID 与校准集重叠 | 自动 ID 断言 + 单独分组报告 |
| 只报成功帧 | RMSE 好看但失败率上升 | 同时报有效帧精度与全样本成功率 |

## 7. 停止条件

出现以下任一情况，停止扩展新功能，只修复 G1：

- 能量守恒 > 1%（非裁切帧）；
- 噪声均值/方差超出有样本量依据的置信区间且原因不明；
- 任一定位器把 NaN/越界结果标为成功；
- 校准与测试样本 ID 出现交集；
- 单位或符号出现 P0 级不一致。
